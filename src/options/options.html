Templates

Four actions appear in the panel, in this order. Bodies are HTML: <p> for a paragraph, <p>&nbsp;</p> for a blank line, <strong> for bold, <br /> for a single line break.

Available variables
  • {{JOB_TITLE}} — job title above
  • {{COMPANY}} — company above
  • {{SENDER_NAME}} / {{SENDER_TITLE}} — your sign-off
  • {{CANDIDATE_EMAIL}} — the recipient's address
  • {{CANDIDATE_NAME}} — only when Outlook supplies a display name
  • {{INTERVIEWER}} — the interviewer named on a screening template
  • {{BOOKING_URL}} — that template's Bookings link, as a clickable link
  • {{GREETING}} — see Greeting below

An unresolved variable blocks the whole action rather than sending a literal {{…}} to a candidate.

Greeting

An address opened from a resume PDF carries no display name, so a greeting usually cannot be personalised. Your templates open without one, which is why this is off.

Only affects templates containing {{GREETING}}. A name is never guessed from an email address.

Used as “Hi there,” when no name is available.

Cleanup of the original application email

After you press Send in Outlook, the extension can delete the LinkedIn application email it came from. It only ever targets the exact message that was open in the tab the compose window was opened from, and only when Send was actually clicked.

What it will never do: send an email, delete after a discarded or unconfirmed send, or delete a message that is not from LinkedIn with an application subject. If anything is uncertain it leaves the email alone and tells you why.
